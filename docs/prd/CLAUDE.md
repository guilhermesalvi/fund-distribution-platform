# Leitura dos PRDs

Para criar ou revisar PRDs nesta pasta, inclusive sem edição, siga a skill `ai-skills:prd`. Ela mantém as convenções dos documentos e orienta a leitura das referências pertinentes à tarefa.

O [PRD 0000](0000-platform-overview.md) é o ponto de entrada do produto e aponta para as capabilities responsáveis.
